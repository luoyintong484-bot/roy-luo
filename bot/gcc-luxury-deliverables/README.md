# GCC 顶级 AI 情感疗愈独立站交付物目录

本目录是面向沙特、阿联酋、卡塔尔三大 GCC 市场的新版本开发交付包。

产品定位已从低价轻量测评升级为：

> 专业级自我觉察与情感疗愈高端数字工具。纯 AI 自动生成深度报告 + 报告专属 AI 情感陪伴，无真人咨询、无社群、无订阅、无自动续费。

交付物：

1. `01_PRD.md`：完整产品需求文档，含业务逻辑、页面流程、性别适配、AI 陪伴规则。
2. `02_TRILINGUAL_COPY_LIBRARY.md`：全场景英阿中三语合规话术库。
3. `03_KNOWLEDGE_BASE_AND_GENERATION.md`：专业知识库、爬虫来源、素材分类、生成逻辑、过滤规则。
4. `04_UI_DESIGN_DEV_SPEC.md`：UI 视觉、组件、RTL、6 页面 + AI 对话页开发标注。
5. `05_COMPLIANCE_CHECKLIST.md`：宗教、法律、内容、视觉、数据五大维度上线验收表。
6. `06_FRONTEND_STRUCTURE.md`：前端路由、组件拆分、数据交互与埋点结构。
7. `09_6_REPORT_SCENE_COPY_LIBRARY.md`：6 款报告全场景话术库，男女分版，英阿中三语样例。
8. `10_STRUCTURED_KB_TAGGING_RULES.md`：结构化知识库标签体系、素材调用规则、校验机制。
9. `11_AUTHORITY_PSYCHOLOGY_THEORY_PACK.md`：权威心理学理论素材包，含书籍 / 机构理论转化规则。
10. `12_AI_COMPANION_SCENE_SCRIPTS.md`：6 套 AI 情感陪伴对话脚本，分报告、分性别。
11. `13_CONTENT_QA_ACCEPTANCE_STANDARD.md`：内容精准度、合规、专业性验收标准。

当前本地 Web MVP 已同步改为 GCC 高客单版本：

- 6 款报告价格区间：`$49` 到 `$129`
- 仅单次付费，无会员订阅
- 用户信息仅采集：性别必选、昵称选填、24 道结构化题、可选私密文本
- 完整报告含 7 大模块
- 解锁后出现 8 轮 AI 深度情感陪伴入口
- 支持 EN / AR 与 RTL
- 报告生成器已加入结构化标签匹配、GCC 场景素材、理论支撑标签与 AI 陪伴场景锚定
