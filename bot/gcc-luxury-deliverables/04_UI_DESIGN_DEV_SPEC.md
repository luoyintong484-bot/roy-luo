# UI 设计开发标注

## 1. 视觉方向

主调性：GCC 顶级轻奢情感疗愈风。

关键词：

- 私密
- 高级
- 安静
- 有温度
- 男女皆适配
- 本土文化尊重

## 2. 色彩

| Token | 色值 | 用途 |
|---|---|---|
| `--deep` | `#080B0F` | 主背景 |
| `--night` | `#0D1420` | 深靛蓝层 |
| `--panel` | `#111A22` | 卡片/弹窗 |
| `--panel-2` | `#17252A` | 报告模块 |
| `--ink` | `#F7F1E6` | 主文字 |
| `--muted` | `rgba(247,241,230,.68)` | 次级文字 |
| `--gold` | `#D8B56D` | 高端、价格、重点 |
| `--mint` | `#7AD7BF` | 主 CTA |
| `--coral` | `#D98E7D` | 错误与危机提示 |

## 3. 字体

英文：

- Inter / system-ui
- Hero 40-88px
- 正文 16-18px

阿语：

- Cairo
- 正文行高 1.65-1.8
- 禁用宗教书法风格

## 4. 页面

### 4.1 首页 / 社媒落地页

模块：

- 极简顶栏：Logo、EN/AR、Begin。
- Hero：情感空虚主标题 + 副标题 + CTA。
- 信任标签：匿名、单次付费、40+ 页、8 轮陪伴。
- 高端交付卡：无订阅、永久查看、PDF 价值。

### 4.2 报告列表

6 张卡片：

- 标签
- 标题
- 副标题
- 情感钩子
- 划线指导价
- 当前价格 + SAR
- CTA

### 4.3 问卷页/弹窗

字段：

- 性别必选。
- 昵称选填。
- 私密一句话选填。
- 24 道结构化题，1-5 分。

禁止：

- 出生日期。
- 出生地点。
- 真实姓名。

### 4.4 免费预览页

展示：

- 第一模块 15%。
- 状态标签。
- 截断钩子。
- 完整版价值说明。
- 退款与隐私信任小字。

### 4.5 完整报告页

展示：

- 7 个报告模块。
- 免责声明。
- 返回报告按钮。
- AI 情感陪伴入口。

### 4.6 支付页

展示：

- 产品名称。
- 美元 + SAR。
- 包含内容。
- 单次付费、无订阅、无自动续费。
- 退款规则。

### 4.7 AI 对话页/组件

样式：

- 柔和圆角气泡。
- AI 消息浅底。
- 用户消息薄荷色透明底。
- 轮次计数 0/8。
- 不强制弹窗。

## 5. RTL 适配

必须镜像：

- 导航。
- 卡片 CTA 对齐。
- 表单 label。
- 步骤顺序。
- 对话气泡方向。

不镜像：

- 数字。
- 价格。
- 品牌 Logo。
- 邮箱与 URL。
